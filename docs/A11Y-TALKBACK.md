# TalkBack 수동 검증 스크립트 (#224)

설정 → 접근성 → TalkBack 켜기. 아래를 위→아래로 스와이프하며 낭독을 확인합니다.

## 홈
1. **캐릭터** — "내 캐릭터, 쉬고 있어요" (또는 "걷고 있어요"). 고정 문구만 읽히면 실패.
2. **캐릭터 탭** — "쓰다듬기" 액션 라벨이 들리고, 탭 후 **대사가 낭독**되는지(live region).
3. **컨디션** — "컨디션 / 78, 100점 만점 · 좋음" 한 문장. "78퍼센트"만 들리면 실패.
4. **컨디션 탭** — 설명 다이얼로그가 열리고 제목부터 읽히는지.
5. **오늘 XP** — "오늘 XP 진행 / 120 XP · 하루 목표 200 XP".
6. **카드 제목** — 제목 단위 이동(TalkBack 읽기 제어 → 제목)으로 카드 사이를 건너뛸 수 있는지.
7. **레벨업 카드**(발생 시) — 나타날 때 자동 낭독되는지.

## 성장
8. **레벨 진행** — "레벨 진행 / 레벨 3 · 누적 520 XP".
9. **성향축** — "걷기 / 45 퍼센트" 식으로 축 이름과 값이 함께.

## 위젯
10. 홈 화면 위젯의 진행바 — "오늘 XP 120, 하루 목표 200 XP".

## 판정
- 원시 퍼센트("78퍼센트")가 들리는 곳이 하나도 없어야 합니다.
- 라벨과 값이 **끊겨서** 들리는 곳이 없어야 합니다(별개 노드로 흩어짐).
